COCINARTE - PUBLICAR EN GITHUB PAGES

1. Descomprime este ZIP.
2. Sube TODO el contenido de la carpeta BakeryloVE a la raíz de tu repositorio de GitHub.
   Es importante que index.html quede directamente en la raíz del repositorio.
3. En GitHub abre Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), y guarda.
6. Espera unos minutos. GitHub mostrará el enlace público de tu página en Settings > Pages.

IMPORTANTE:
- No separes la carpeta assets: contiene las imágenes de la página.
- Se cambiaron los nombres de imágenes para evitar espacios y problemas de mayúsculas/minúsculas.
- Las imágenes utilizadas por el sitio están guardadas localmente dentro del proyecto; no dependen de enlaces externos de imágenes.
- Mantén la estructura de carpetas tal como está al subirla.
